# Round 79 — preserve drafts during locale changes and hidden notes

An external language change could reload a page while notes, searches, tasks or layout controls held user work. Defer that reload while protected work exists, show an explicit reload control, and require confirmation before leaving unsaved work. Once deferred, a later event cannot automatically reload the page; a rollback to the loaded preference clears the notice.

Keep unsaved drafts from disabled or removed note widgets accessible in a recovery section with selectable read-only text and explicit discard. Never persist private drafts to sync or assign them to a different widget. Clean removed sessions can be pruned. Pending saves cannot be discarded until settled. Drafts remain page-lifetime only; a crash/close can still lose unsaved text. Add Round 35 tests and static contracts, EN/RU messages, and styles. Real browser acceptance is still required.
