# Round 103 — session storage degradation

The per-tab blocked destination registry previously stopped matching if session removal failed, suppressing the existing local history/statistics path and potentially leaving an old URL. Keep session writes best-effort, retain an authoritative in-memory overlay for failed writes, and try a durable null tombstone when deletion fails. Failed matches/closed tabs mask old destinations; unavailable reads fall back to no exact URL. Successful writes discard the overlay. Both storage methods failing across a worker restart cannot be made durable without another storage dependency; do not claim that scenario is solved. Fixtures cover removal/write/read failures, failed matching, recovery, worker restart after a tombstone and unavailable session storage.
