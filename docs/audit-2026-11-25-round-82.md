# Round 82 — task draft generation

A local-task acknowledgement previously compared only the current text against the submitted text. When a user edited the input away from and back to that text while the worker was committing, the acknowledgement erased the newly typed draft. Track the generation of each changed input value and capture both generation and value at submission. Clear only the matching generation after success; DOM rebuilds and unchanged assignments do not advance the generation. Failed submissions keep their draft. Round 35 fixtures cover rebuilt forms, edits away and back, unchanged assignments, and stale acknowledgements. Manual acceptance should exercise rapid edits during a deliberately delayed task save.
