# Round 84 — bound external widget responses

Custom IP, weather and geocoding providers may return arbitrarily large JSON payloads. Previously the page called Response.json() without a byte budget, allowing an oversized response to consume memory before parsing. Stream the decoded response with a 1 MiB budget, preserve UTF-8 across chunk boundaries, cancel rejected streams without waiting for cancellation, retain the existing fetch timeout and allow the exact size boundary. This cap is deliberately well above ordinary responses from the supported providers. Round 34 fixtures cover misleading Content-Length, stream cancellation, UTF-8, exact-limit acceptance, malformed JSON and empty bodies.
