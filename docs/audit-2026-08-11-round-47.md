# Deep audit round 47 — finalization, recursive static roots, and profile exactness

## Scope

Independent continuation from exact `master` commit `5ecfbf3e52f1e8c27358a5589277cdc69c821a24`. The audit rechecked the Round 44–46 output lifecycle and watch recovery changes, then widened into late finalization safety, recursive static-tree filesystem types, one-shot/release finalization, and cross-profile reuse of a custom safe `--outdir`.

## Confirmed defects

1. Round 45 moved generated-output invalidation to `onStart`, but successful `onEnd` static finalization no longer revalidated the output filesystem immediately before `copyStaticAssets()`. A late output-path replacement with a junction or symlink after compilation could therefore make copied HTML/CSS/icons/locales/manifest use a stale safety decision.
2. `listRegularTree()` used `readdir()` directly on recursive static roots. A root `icons/` or `src/_locales/` symlink/junction could be traversed, while a wrong-type root such as a regular file failed with `ENOTDIR` before recovery watch metadata was returned.
3. Nested symlinks/junctions and other special entries still threw immediately instead of becoming structured watch errors, so correcting the bad entry could require an unrelated edit or watcher restart.
4. Generated cleanup was profile-narrowed. Reusing one safe `--outdir` for a full build and then blocker-only build preserved stale `newtab.js`, `newtab.html`, `newtab.css`, and `newtab-gate.js`, contradicting the blocker-only build validator and producing a mixed-profile output tree.
5. Recursive static-tree validation lived only in `createStaticAssetWatchPlugin()`, which is intentionally registered only in `--watch` mode. Ordinary one-shot/release builds therefore reached `copyStaticAssets()` without the same root/nested link and wrong-type validation.

## Corrections

- Revalidate `assertSafeBuildOutputFilesystem()` after compilation and immediately before static finalization.
- Keep late output-link failures fail-closed; static finalization does not run through the replaced path and cleanup still attempts bounded invalidation.
- Inspect every recursive directory position with `lstat()` so root and nested links/junctions are never followed.
- Convert wrong-type roots and nested special entries into structured errors while preserving real parent `watchDirs` for automatic recovery.
- Ensure files behind a linked recursive static root never enter `watchFiles`.
- Reuse the same recursive static-tree validation at the start of `copyStaticAssets()`, so one-shot/release builds and successful watch finalization enforce the same filesystem rules.
- Make generated-output invalidation use the complete known generated artifact universe, so blocker-only builds remove stale full/new-tab artifacts when an output directory is reused.
- Preserve unrelated output files outside the build-owned generated path list.

## Regression coverage

Round 47 adds executable fixtures for wrong-type root recovery, missing-root recovery after correcting the type, Windows junction/POSIX symlink rejection at the recursive root, nested link rejection and automatic recovery, external sentinel preservation, late output-path replacement before static finalization, and full-to-blocker exact cleanup in a shared output directory. Static contracts additionally require every `copyStaticAssets()` finalization, including ordinary one-shot builds, to invoke the shared recursive-tree validator; the normal full, blocker-only, and Google CI builds execute that path on Windows.
