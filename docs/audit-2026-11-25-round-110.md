# Round 110 — coherent Options locale after restore

Options loaded a language catalog independently from its initial settings snapshot and never refreshed it after backup/sync restore. A restored locale could be shown in the selector while the entire UI remained in the old language. Load the catalog for the exact committed snapshot before publishing state. Successful actions and initialization rebuild using the matching catalog; retained General forms keep their old UI language and draft values until saved/discarded. Explicit language changes use the existing acknowledged refresh path rather than a separate page reload. Fixtures verify supplied-preference loading and merged fragments without another storage read. Real Options UI acceptance remains manual QA.
