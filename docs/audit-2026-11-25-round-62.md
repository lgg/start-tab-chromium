# Round 62 — Options form lifecycle

- General form uses the settings/runtime/locale baseline it actually displayed; a failed save does not silently rebase the draft.
- Unrelated mutations ask before discarding unsaved General fields; declining leaves the form and storage untouched.
- Failed General saves preserve input and offer explicit Cancel to load refreshed settings. Closing the page with unsaved inputs requests a browser unload confirmation. Partial settings/locale failures preserve the form rather than claim both writes succeeded.
- State reload publishes only after all reads succeed; render always releases its reentrancy guard. Empty numeric inputs no longer become zero through Number("").
- New theme creation uses the dedicated append-only save path, rather than the upsert path which could modify an existing theme if its ID collided.
- Round 35 fixtures and source contracts extended; real browser UI acceptance remains needed.
