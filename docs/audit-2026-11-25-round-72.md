# Round 72 — Calendar event validation and literal interpolation

Google Calendar previously allowed cancelled, incomplete, impossible-date and duplicate events to consume the visible result limit. Validate event identity, cancellation and matching start/end representations, reject reversed ranges, and deduplicate accepted IDs before counting the display limit. Valid all-day dates remain separate from timed events. Continue bounded pagination to find valid results. Share date-only validation with the weather parser. Timed ISO values without an offset remain accepted for compatibility; calendar timezone conversion is not changed.

Runtime translation interpolation now performs one pass on the original source template. A user-provided title containing another placeholder is preserved literally, and missing or prototype-inherited keys are not substituted. Extended Round 21 fixtures with mocked Calendar pages and literal interpolation cases. Actual Google account data remains a browser acceptance task.
