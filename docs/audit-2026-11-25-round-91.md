# Round 91 — coherent Options locale baseline and failed-action draft retention

Options previously fetched a committed layout/runtime snapshot and then read its locale independently. A concurrent atomic layout/locale transaction could produce mismatched optimistic baselines. Include the committed locale preference in the same locked page snapshot and consume it directly in Options. Also keep a dirty General form after an unrelated action fails, even when the user confirmed that a successful action could replace the draft; the failed action did not justify deleting it. Round 16 fixtures cover a provisional combined transaction, rollback and successful atomic layout/locale replacement. Static contracts cover the Options recovery path; real browser QA should type a General draft, trigger a failing action in a different section, and confirm the draft remains editable.
