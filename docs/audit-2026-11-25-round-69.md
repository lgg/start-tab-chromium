# Round 69 — retain theme dialog panels and optional numeric fields

Switching between background kinds or animation effects previously recreated the controls from the originally saved theme, discarding edits made during the current dialog. Cache each panel's actual controls and reader for the dialog lifetime, detaching inactive controls so their validation cannot prevent saving the selected panel. Re-selecting a kind or effect restores the edited controls. Only the selected kind/effect is persisted; other cached drafts remain ephemeral.

Use a shared numeric field parser in Options, block and theme editors. Blank optional inputs retain their fallback instead of Number("") becoming 0; explicitly entered zero remains valid where allowed. Extended Round 35 fixture coverage. Real browser theme dialog interactions remain part of manual QA.
