# Round 83 — onboarding interaction guard and task navigation warning

Onboarding evaluated page-local guards before an asynchronous read of committed onboarding state. While that read waited for a storage transaction, the user could start editing or open another dialog; the wizard would then cover the live work. Recheck the guards synchronously after the read, include search drafts and other open dialogs, and extend the existing beforeunload guard to pending or unsubmitted local-task work. Search drafts alone do not block ordinary search navigation. These protections do not make page-lifetime drafts durable across a browser crash or forced reload. Static regression contracts cover the UI wiring; manual QA should hold the storage lock, begin editing or open a dialog while the wizard waits, and confirm it does not mount. Verify closing a tab containing an unsubmitted task prompts for confirmation.
