# Deep audit round 38 — asynchronous and stale-context hardening

## Scope

Independent continuation from Round 37 across all tracked source/configuration files and declared screens. This pass concentrated on early pre-module UI, asynchronous DOM insertion, stale renderer messages, modal re-entry, localization catalogs, service-worker mutation boundaries, storage failure behavior, package profiles, documentation, and the complete historical validation chain.

## Confirmed defects

1. The early disabled/Split View gate loaded only `messages.json`, although required strings live across multiple locale catalogs. Explicit Russian selection therefore fell back to English for gate text and the native-new-tab action.
2. Changing the explicit locale while an early gate was visible did not refresh that gate.
3. In an identified Split View context, a rejected `chrome.tabs.query` aborted `apply()` and was swallowed by the outer readiness promise. The normal Start Tab UI could therefore appear where the safety gate should fail closed.
4. Note, Local Tasks, and paginated link runtime messages validated only the instance ID's previous value. If the block had been removed or changed to another type, the service worker could acknowledge a mutation that normalization silently discarded.
5. Statistics is appended asynchronously in Options. A direct `#statistics` URL or first navigation click could set the hash before the target existed and never scroll after insertion.
6. Block and theme editors allowed rapid re-entry. Multiple native modal settings dialogs could coexist with duplicate static ARIA title IDs.

## Corrections

- The early gate now merges base, roadmap, and Round 7 locale catalogs, includes localized gate-specific strings, refreshes on locale changes, and localizes untitled tab fallbacks.
- Split View tab enumeration now converts query failure to an empty candidate list and still renders the safety overlay.
- Added an explicit current-settings target guard for note, tasks, and link-page mutations. Removed or type-changed blocks now reject stale writes instead of returning a false success.
- Deferred Statistics insertion now restores a matching URL fragment for both the normal and unavailable-state sections.
- Added a shared settings-dialog guard that focuses the existing open editor, prevents modal stacking, and generates unique ARIA title IDs.
- Added Round 38 executable fixtures, static contracts, locale coverage, manual QA, CI wiring, and self-hosted contract coverage.

## Validation boundary

Automation covers deterministic locale merging contracts, target/type invariants, fragment matching, modal-entry guards, type safety, historical regressions, and package builds. Physical focus/scroll behavior in every Chromium fork, vendor Split View internals, real extension storage failures, and live external APIs remain explicit browser-level manual checks.
