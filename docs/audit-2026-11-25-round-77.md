# Round 77 — date formatting and validated search substitution

The date widget previously replaced tokens sequentially, so localized text containing "mm" or "ss" could be corrupted (e.g. Finnish month names). Perform a single pass over the source pattern, explicitly select h23 for midnight, and reuse one Intl formatter and parts extraction for both date/time per tick. Search template validation at settings import used a sentinel value only; the actual user query could make the URL invalid, or malformed UTF-16 could throw during encoding. Validate the final HTTP(S) URL, normalize lone surrogates via UTF-8 conversion, and surface a visible error without losing the search draft. Existing valid custom provider templates, including intentional hostname templates, remain supported. Extend Round 34 fixtures.
