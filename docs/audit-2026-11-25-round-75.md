# Round 75 — finite focus statistics and rollback-safe deduplication

Corrupt/imported finite but enormous counters can overflow when several durations are added; JSON would then serialize Infinity as null. Normalize counters to a safe numeric ceiling and use saturating arithmetic for all totals and domain updates. Validate event timestamps before recording statistics, ignore invalid persisted completion timestamps, use one timestamp for day attribution and completion deduplication. A wall-clock rollback must not suppress avoided visits until the old future timestamp is reached; count one new visit and start a new dedupe window. Extend Round 17 fixtures with extreme numeric values, invalid times, and rollback scenarios. Valid ordinary counters and fractional durations remain unchanged. This is bounded representation, not a promise of unbounded historical precision.
