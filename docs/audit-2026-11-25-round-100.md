# Round 100 — incomplete Google Drive backup searches

Drive's files.list response may report incompleteSearch. The old request did not request this field and could mistake a partial listing for an absent backup or select an older file while the newest one was omitted. Explicitly request incompleteSearch, reject partial or malformed flags before selecting any file, and reject whitespace pagination tokens. Preserve the complete listing path. Regression fixtures cover both upload and restore, empty and nonempty partial listings, malformed results and a normal complete upload. Live Drive/OAuth acceptance remains necessary.
