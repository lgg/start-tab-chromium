# Round 104 — reject malformed backup payloads before restore

A syntactically valid backup envelope with empty or unrelated storage could be normalized into default settings and overwrite real user data. Reject payloads with no recognized data section and malformed present primary sections before normalization or mutation. Keep valid legacy partial backups and explicit empty blocklists compatible. Do not require every modern section or reject unknown optional fields. Fixtures cover invalid local imports, unchanged recovery state, valid historical data, empty blocklists and an actual exported snapshot. This is not a cryptographic integrity guarantee for arbitrary local JSON.
